# @next-safe-action/adapter-routes

Expose selected next-safe-action actions through JSON mutation route handlers. The same actions remain usable with React hooks.

Requires next-safe-action 8.8 or later. Optional OpenAPI generation is available from `@next-safe-action/adapter-routes/openapi`.

See the [route adapter documentation](https://next-safe-action.dev/docs/integrations/routes) for setup, security requirements, stateful actions, and OpenAPI configuration.
